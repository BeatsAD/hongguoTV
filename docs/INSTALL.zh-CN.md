# 安装与使用指南

本指南适用于 [BeatsAD/hongguoTV](https://github.com/BeatsAD/hongguoTV) 的 Kotlin 原生个人分发版。最低 Android 8.0，安装一个 APK 即可联网使用，无需部署 Node 或 Docker。系统与设备边界见[兼容性说明](COMPATIBILITY.zh-CN.md)。

## 首次安装

1. 在电脑或手机打开[最新 Release](https://github.com/BeatsAD/hongguoTV/releases/latest)，下载附件中的 `hongguo-版本号.apk`，例如 `hongguo-1.0.0.apk`。1.0.0 起只上传一个 APK。
2. 通过 U 盘或电视支持的文件传输方式，把 APK 复制到电视。在文件管理器中打开它，按电视系统提示允许该文件管理器安装未知来源应用。
3. 安装后从电视应用列表打开客户端，连接可用网络，进入首页、分类、榜单或搜索。APK 不要求登录 hongguo 或抖音账号。

如果你使用已授权连接的 ADB，也可以在电脑执行：

```sh
adb devices
# 多台设备时，将 DEVICE_SERIAL 替换为目标电视的实际序列号
adb -s DEVICE_SERIAL install -r /absolute/path/to/downloaded.apk
```

安装前先核对设备与安装包。`-r` 用于保留数据覆盖安装，不能绕过签名冲突、版本降级限制或设备系统要求；无需卸载旧包尝试。

## 保留数据升级

本渠道包名为 `com.hongguotv.nativeapp.playbackfix`。同包名、同签名且构建号更高时，可覆盖升级并保留本机片单、进度与设置。

- 已安装 0.10.x：首次升级到 1.0.0 需从本仓库手动下载并覆盖安装一次。旧版读取单独的 `update.json`，不能发现新的 APK-only 发布；不要卸载或清除数据。
- 已安装 1.0.0 或更新的本渠道分发版：进入「设置 → 版本与更新」，检查和下载新版，选择安装，再确认系统安装提示。首次需要允许本应用安装未知来源应用。
- 早期不带在线更新的开发版：先从本仓库手动下载并覆盖安装一次，再使用应用内更新。
- 上游、历史包或自行构建：先核对包名、签名与构建号。包名不同可能会并存，数据不会自动迁移；签名不同不能直接覆盖。

更新会核对下载大小、SHA-256、实际包名、版本与签名。后台或播放中会取消更新请求；设置中可关闭自动检查与下载。下载失败时可稍后重试，不影响当前安装。不要通过卸载、清除数据或降级解决冲突。

重要片单可先通过「设置 → 手机备份与恢复」导出备份。备份包含个人记录，请妥善保管，不要上传到公开 Issue。

## 遥控器操作

| 场景 | 操作 |
| --- | --- |
| 浏览 | 方向键移动焦点，确认进入详情；续播卡片可直接播放 |
| 剧卡操作 | 菜单键或长按确认，打开收藏、稍后看等操作 |
| 播放与暂停 | 确认键 |
| 快进与快退 | 左右方向键，长按连续跳转 |
| 选集 | 播放时按下方向键，定位后确认换集 |
| 更多操作 | 播放时按上方向键或菜单键 |
| 返回 | 先关闭选集或收起浮层，再退出播放；返回列表恢复浏览位置 |

设置中可以调整默认清晰度、倍速、画面模式与自动连播；播放菜单可设置定时停止。完整画面保留比例，等比铺满可能裁切字幕，拉伸铺满会改变比例。

## 手机输入与备份

手机和电视需要连接同一局域网。打开应用中的手机输入或备份窗口，手机扫码后用浏览器操作，无需安装手机端 App。

- 手机输入：输入剧名并发送到电视搜索。
- 备份：下载本机记录的 JSON 文件，或选择已有备份上传；恢复前需要在电视查看并确认。
- 搜索页手机输入会话最长 15 分钟，备份会话最长 5 分钟。离开相应页面、关闭窗口或应用进入后台后失效；过期后重新打开生成二维码。

这些二维码不是 hongguo 或抖音登录入口，当前没有平台账号登录或云端同步。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 无法安装或提示不兼容 | 核对 Android 版本、APK 是否完整、包名、签名及构建号；参阅兼容性说明 |
| 更新下载失败 | 确认电视可访问 GitHub API、GitHub 及附件下载域名，稍后重试；也可手动下载同渠道更高版本覆盖安装 |
| 搜索、分类或播放失败 | 记录错误原文，尝试其他剧或稍后重试；第三方接口变化可能需要新版 APK |
| 有声音但黑屏、解码失败 | 尝试更低清晰度；仍失败时记录电视型号、系统版本与诊断信息 |
| 手机无法连接 | 确认同一局域网，检查访客网络或设备隔离，重新生成二维码 |
| 收藏或进度没有同步 | 当前记录在本机，不与 hongguo / 抖音账号同步；设备迁移使用备份与恢复 |

普通问题使用 [Bug 模板](https://github.com/BeatsAD/hongguoTV/issues/new?template=bug_report.yml)，附版本、设备、步骤及脱敏后的诊断信息。安全问题请使用[私密报告](https://github.com/BeatsAD/hongguoTV/security/advisories/new)。
