# 仓库协作与安全设置

本页记录 `BeatsAD/hongguoTV` 的仓库管理约定。它描述设置用途，不代表应用已经完成安全审计；实时开关以 GitHub 设置页为准。

## 展示与反馈

- 默认分支为 `main`，仓库简介使用中文，README 提供中文安装、使用、兼容性、截图及许可说明。
- Topics：`android`、`android-tv`、`androidtv`、`kotlin`、`media3`、`exoplayer`、`short-drama`、`hongguotv`、`chinese`。
- Issues 已开启；Bug 与功能建议使用表单。安全问题走私密报告，避免在公开反馈中披露漏洞与私人数据。

## 主分支保护

`main` 要求通过 PR 修改，规则对管理员生效；禁止强制推送和删除分支，并要求解决审查讨论。新提交会使旧的批准状态失效。

当前为个人维护仓库，所需批准人数设为 0，不要求自己批准自己的 PR。没有将现有按路径触发的 Android 检查设为所有 PR 的必需状态，以免纯文档 PR 永久等待不会运行的检查；原生代码仍按项目要求验证。后续若增加强制状态检查，应先确保该检查对所有相关 PR 都会运行。

提交、推送、创建 PR、合并和发布是分别执行的动作。原生路径合入 `main` 还可能触发个人分发工作流，应在合并前核对其影响。

## 依赖安全提醒

已开启 GitHub Dependabot 漏洞提醒。提醒依赖 GitHub 可识别的依赖图与漏洞数据库，不能覆盖所有依赖、业务逻辑或运行时风险；“没有提醒”不表示安全。

本次仅启用提醒，没有批量升级依赖，也没有开启自动合并依赖 PR。维护者应核对受影响的实际构建路径，按最小范围修复并执行相关测试。

## 私密漏洞报告

已开启[私密漏洞报告](https://github.com/BeatsAD/hongguoTV/security/advisories/new)。报告材料、维护范围与安全要求见[安全政策](../SECURITY.md)。请先私密沟通，再协调修复与公开披露；不要把密钥、Cookie、签名播放地址、设备身份或私人备份写进公开 Issue。
