# 红果 TV 原生独立版

这是独立的 **Kotlin + Android 原生 View + Media3** 工程，最低 Android 8.0 / API 26。安装一个 APK，联网后可直接浏览和播放，无需部署 Node、Docker 或填写服务器地址。

[中文安装与使用指南](../docs/INSTALL.zh-CN.md) · [兼容性说明](../docs/COMPATIBILITY.zh-CN.md) · [界面截图](../README.md#界面展示)

- 应用名称：红果 TV
- 个人分发包名：`com.hongguotv.nativeapp.playbackfix`，沿用当前测试设备数据。历史正式包 `com.hongguotv.nativeapp` 与旧 `com.hongguotv` 独立。
- 收藏和历史独立保存在本机，不自动迁移旧版数据。
- APK 不含 JNI 库，可由 Android 在 ARM32、ARM64、x86、x86_64 上运行；视频解码能力依赖设备。
- 个人分发源码分支：本 fork 的 `main`。
- [下载个人分发 APK](https://github.com/BeatsAD/hongguoTV/releases/latest)；沿用现有个人签名，不是上游正式签名包。

当前个人分发渠道以 [Releases](https://github.com/BeatsAD/hongguoTV/releases/latest) 为准。下文保留各版本的功能与历史验证记录；旧版签名、包名及验收结果不代表当前个人分发包。

### 本地开发版 0.10.4

- 2026-11-11 播放取址修复：改用当前签名 GET 接口并兼容 `data.video_model_data`；签名内的设备身份和版本与请求参数保持一致。注册身份取址为空时最多额外尝试一次上游固定参数的兼容请求，不混用本机 Cookie；兼容请求成功后仅在本次运行复用此路径，保留原有身份和数据。访问拒绝、限流、业务拒绝及格式错误不触发兼容切换。当前恢复播放依赖兼容路径，未将其表述为独立注册身份已恢复。
- 修复播放中确认换集时，关闭上一集 HTTPS 视频响应触发主线程网络异常的问题。当前播放、下一集预载、退出和过期结果共用后台关闭逻辑；关闭标记阻止后续读取，重复释放不重复执行，Activity 销毁后的迟到结果仍可清理。验证结果以本地修复记录为准，尚未重新安装索尼电视验收。
- 增加匿名播放设备注册，使用服务端下发的 device_id / install_id，搜索、首播与下一集预载优先复用身份；身份存入应用私有数据，重试不轮换身份，不需要账号登录。播放的上游兼容路径单独使用完整参考参数。注册有超时、失败冷却和限流保护，身份与 Cookie 不写入诊断日志。
- 搜索首批空列表也核对官网同类型结果，分页保持来源一致；官网失败继续显示错误，不误报“没有这部剧”；类型过滤后空批次保留后续游标，可手动继续，不自动循环。首页刷新为空时保留同分类已有内容；分类返回空列表却标记有后续内容时提示异常。
- 播放取址空响应或空数据最多立即补取一次，每次取址限时 10 秒；业务拒绝、限流与访问拒绝不反复补取。短暂传输故障改为 5 / 15 / 60 **秒**退避，429、401/403 与服务端 `Retry-After` 的保护不变；此前已保存的冷却仍按原截止时间到期。
- 视频索引首次读取由 256 KiB 改为 32 KiB，按需补齐索引；媒体改为复用最多 2 MiB 的分段连接，每次将已收到的最多 64 KiB 数据解密后交给播放器，不再等满 512 KiB。读取保留绝对偏移与分段校验，跳转或退出取消旧连接；网络故障最多切换一次接口提供的同清晰度备用 CDN，401/403/429 和格式错误不切换；逐块复用 AES Cipher，减少重复创建开销。CDN 连接与单次读取最多 8 / 10 秒，索引请求总调用最多 30 秒；持续媒体连接允许暂停或缓冲充足时闲置，不因总调用计时误中断。
- 首次准备后持续缓冲 18 秒、播放后持续缓冲 12 秒时，按现有每集最多三次自动恢复预算尝试本集临时降至 720P / 480P，保留播放位置，不改变全局设置；无更低画质、断网或预算耗尽时显示故障操作。暂停、选集和后台不计入持续缓冲时间。
- 错误提示区分超时、DNS、HTTPS、业务拒绝和服务冷却。错误状态与设置提供“诊断详情”，可查看、复制本次运行最近 80 条脱敏记录，包含请求阶段、HTTP 状态、字节数、耗时、缓冲位置、Media3 错误码、解码器与掉帧。重启后记录清空，不记录签名地址、密钥、搜索词或响应正文。
- 自动化、模拟器与网络探测的结果和边界见本次 `outputs/data-playback-fix-20261028/` 验证记录；没有实体电视验收或发布。

### 本地开发版 0.10.3

- 首页仍先显示本机缓存，联网结果自动应用，不再要求确认“热门已更新”。更新保留当前剧集焦点与浏览位置，弹窗打开时延后应用；失败保留已有内容并提供重试。
- 打开应用或返回页面时，首页、漫剧榜按 30 分钟缓存时效按需更新；不固定轮询首页、榜单或分集。启动可复用 30 分钟内的首页缓存，仍保留最长 7 天的离线内容。手动刷新至少间隔 10 秒，重复点击不会重复发起当前请求；详情和打开选集时也按时效检查。
- 收藏仅在查看收藏页时自动分批检查，每批最多 10 部、串行请求间隔 2 秒；每部自动检查间隔至少 6 小时。手动可检查下一批，每批至少间隔 1 分钟。失败延长等待时间，不在启动时扫描全部收藏，也不在后台唤醒设备。
- 元数据请求失败后按 5 / 15 / 60 分钟退避；收到 429 后至少等待 30 分钟，401/403 后至少暂停 1 小时，并尊重更长的 `Retry-After`。冷却由目录、详情和收藏客户端共享，记录在本机，重启和手动刷新不绕过。以上是保守的客户端策略，不是平台承诺的安全调用配额。
- 搜索备用来源按分类过滤后为空时，最多继续检查 4 个来源页；下一页从实际消耗的位置继续。主搜索失败后暂停尝试 15 分钟，随后允许恢复；主搜索单次限时 5 秒，备用搜索整轮限时 12 秒。超过查找上限仍可继续翻页，不把其他分类充当结果；收到访问拒绝或限流时不切换来源继续尝试。
- 收藏检查同时更新本机剧名、海报、简介等展示信息，保留片单顺序、观看进度与时间。通过分集 ID 摘要识别同集数替换、删减或重排，分别提示“新增集数”或“分集有调整”；旧记录首次建立摘要不误报。
- 播放中保持当前集，新的分集列表在打开选集时按分集 ID 应用；若当前集已被移除，则保留播放现场，返回详情后应用。详情增加手动刷新入口；平台账号和官方手机端片库完整性仍未实现或验证。

### 0.7.0 新增

- **首页更紧凑**：焦点预览固定为一行剧名和一行状态，完整简介留在详情。接着看、收藏有更新各显示最多 8 部，稍后看、热门各最多 10 部；超过后从行末「查看全部」进入集合。本地收藏、最近观看及首页集合每页最多 20 部，避免一次创建全部剧卡。首屏数量不改变本机记录的保存上限。
- **快捷操作保持位置**：收藏、稍后看和隐藏更新当前卡片区域，不重建整个页面；保留每行横向位置，移除当前卡后聚焦相邻卡。返回列表保留页码，并确保恢复的焦点处于可见区域。
- **本机查询不再反复解析记录**：启动在后台载入收藏、历史、设置及首页缓存，之后通过内存索引查询；记录按变更字段合并，由后台串行写入。首页缓存独立存储，兼容迁移旧版记录，生命周期变化会请求及时写入。
- **封面和请求可以取消**：图片按实际显示尺寸采样和裁切，优先处理焦点附近内容；图片等待队列最多 24 项，低内存设备使用 1 个图片线程和 4 MiB 内存缓存，其他设备为 2 个线程和 8 MiB。保留 24 MiB 封面磁盘缓存；离开页面、换集或进入后台时释放旧图片绑定并取消相应请求，翻页与搜索也会取消前一次内容请求。
- **换集复用播放器**：普通换集复用 Media3 播放器与播放视图，更新媒体源和本集监听；故障恢复、退出和后台释放仍走完整清理。播放进度与媒体状态按可见性、播放状态和事件更新，减少后台或隐藏界面的重复工作。
- **预加载靠近片尾**：按当前倍速估算剩余播放时间，在最后 30 秒内且自动连播、网络和缓冲条件允许时准备下一集；每集最多尝试 3 次，尝试间隔至少 15 秒。仍只保留一个结果和最多 1 MiB 开头数据，2 分钟失效，取消及失败走普通加载流程。
- **避免只播声音却黑屏**：过滤已知不兼容的视频格式；优先遵守默认清晰度，若只有更高清晰度可用则显示「兼容资源」。视频轨道无法播放时显示失败操作，不把音频 READY 当成视频成功。
- **续播少一层操作**：最近观看和首页续播确认后直接播放，退出回原列表；播放中「↓」直接选集，「↑ / 菜单键」打开更多操作。选集取消恢复原播放或暂停状态。

- 自动连播开启、非按流量计费网络且当前集稳定播放后，预解析下一集并保留最多 1 MiB 开头数据。只保留下一集，2 分钟后失效；切换清晰度、退出/后台、网络变化时取消。未完成、过期或失败时回到正常播放流程。视频索引仍受原 8 MiB 上限约束，媒体始终在内存处理。

### 0.5.0 新增

## 使用

1. 从[本仓库 Releases](https://github.com/BeatsAD/hongguoTV/releases/latest) 下载个人分发 APK，首次拷贝到电视安装，或通过 `adb install -r APK文件路径` 覆盖安装。同包名、同签名且版本更低的安装可保留数据升级；之后在设置 → 版本与更新中完成更新。
2. 在电视应用列表打开「红果 TV」，进入首页或搜索。
3. 首页续播和最近观看确认即播放；发现新剧时确认进入详情，选择开始观看。设置中可选择 480P / 720P / 1080P 上限和是否自动连播。

播放中：确认键暂停/播放；左右跳转 10 秒，长按连续跳转；向下直接打开选集，向上或菜单键打开播放、上下集、倍速等更多操作。返回键先关闭选集或收起进度条与菜单，再退出播放；从列表直接续播时回原列表，从详情开始播放时回详情。列表恢复原卡片和页码。

## 构建

需要 JDK 17、Android SDK Platform 36 / Build Tools 36.0.0。Gradle 8.14.3 包装器已包含；不需要 npm、Node 或 React Native。设置 `ANDROID_HOME`，或在本目录的 `local.properties` 写入 `sdk.dir=SDK绝对路径`。

```sh
# 仓库根目录：开发包直接可安装，无需发布私钥
./kotlin-tv/gradlew -p kotlin-tv :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
adb install -r kotlin-tv/app/build/outputs/apk/debug/app-debug.apk
```

本地 Debug 包使用 `com.hongguotv.nativeapp.playbackfix`，不检查或下载在线更新，也不请求安装其他应用的权限。`distribution` 使用同一包名，关闭调试、支持个人渠道在线更新。本机默认调试签名可能与个人分发签名不同，覆盖升级必须同时满足包名、签名匹配和版本递增。

个人分发 APK 沿用既有个人签名，历史 `release` 包使用独立发布密钥。**私钥和口令不随源码提供**。构建签名包时，配置以下环境变量，或创建被 Git 忽略的 `kotlin-tv/keystore.properties`：

```properties
storeFile=/absolute/path/to/your-release.jks
storePassword=your-password
keyAlias=your-alias
keyPassword=your-password
```

对应环境变量：`HONGGUOTV_KEYSTORE`、`HONGGUOTV_STORE_PASSWORD`、`HONGGUOTV_KEY_ALIAS`、`HONGGUOTV_KEY_PASSWORD`。覆盖更新已有安装必须继续使用其原签名，不要卸载或清除数据来绕过冲突。

```sh
# 仓库根目录，配置既有个人签名后：按目标 Release 填写精确版本
# 以下复现 0.10.5 的构建 10003
HONGGUOTV_VERSION_CODE=10003 HONGGUOTV_VERSION_NAME=0.10.5+3 ./kotlin-tv/gradlew -p kotlin-tv :app:lintDistribution :app:assembleDistribution --console=plain
# 输出：kotlin-tv/app/build/outputs/apk/distribution/app-distribution.apk
```

渠道版本基线来自 `distribution/channel.properties`，本地 Debug 默认版本来自 `app/build.gradle.kts`；二者用途不同。云端构建号递增规则及复现步骤见 [AUTO_UPDATES.md](AUTO_UPDATES.md)。`scripts/build-kotlin.sh` 用于历史 `release` 包，不构建个人渠道的 `distribution` 包。

## 工程结构

- `core/`：纯 Kotlin 内容列表、搜索、详情、请求签名、播放地址解析、MP4 索引和分段处理；可在 JVM 测试。
- `app/`：原生电视界面、遥控器焦点、本地收藏/进度、Media3 播放器及自定义 DataSource。
- `core/src/test/`：固定签名对照、NIST AES-CTR 向量、跨样本/非对齐分段、AVC 索引恢复及畸形输入校验。
- `tools/signing-oracle.cjs`：仅开发期生成兼容性测试样本；运行、构建 APK 不需要它。

播放器直接通过 HTTPS 分段拉取数据，经本机 Kotlin 处理后交给 Media3。没有 JS 引擎或常驻内容服务。仅在用户使用手机输入或备份功能时，APK 临时监听局域网 HTTP；搜索页手机输入会话最长 15 分钟，备份会话最长 5 分钟，离开相应页面、关闭窗口或应用进入后台后停止。备份下载每次二维码一次，上传成功后关闭会话并等待电视确认。页面不处理平台账号凭据或媒体。媒体只在内存中处理，不下载整部剧到存储。元数据响应、封面大小、索引数量和播放缓冲均有上限。

```sh
# 可选联网检查：真实网站和内容接口，网络变化可能导致失败
./kotlin-tv/gradlew -p kotlin-tv :core:run
# 漫剧分类、搜索两页、详情与真实视频分段检查
./kotlin-tv/gradlew -p kotlin-tv :core:run --args=--comic
# 漫剧排行榜首两页及末页：来源名次、热度、分页和重复检查
./kotlin-tv/gradlew -p kotlin-tv :core:run --args=--ranking
# 重新生成签名对照样本才需要 Node
node kotlin-tv/tools/signing-oracle.cjs
```

## 验证边界

个人分发版的源码提交、版本、构建号及校验和见对应 [Release](https://github.com/BeatsAD/hongguoTV/releases/latest)；自动单元测试、lint 和签名构建通过不等于模拟器或实体电视验收。

既往版本的 JVM 测试、Android lint、APK 构建与模拟器检查分别记录在对应交付文档中，例如 [0.7.0 交付与验证](RELEASE_0.7.0.md)。历史记录只证明其记录的版本和范围。最低 API 26 配置和静态检查不等同于实体电视验收；**Android 8.0 实体电视的芯片解码、音频输出和长期稳定性尚待实机验证**。遇到设备解码失败可尝试 720P，仍失败需对应电视的日志。

内容来自第三方接口；接口、签名、内容可用性或地区网络变化可能需要更新 APK。此版本不是内容平台官方客户端。
