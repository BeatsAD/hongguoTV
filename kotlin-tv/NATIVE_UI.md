# 原生电视浏览界面

生产代码继续使用 Kotlin / View / Media3。`MainActivity` 管理详情、播放器与设置；`NativeBrowseController` 管理左侧导航、页面状态、请求取消与扫码服务。`PosterCardView` 供首页、分类、搜索、榜单与本机片单共用；`PosterGridView` 使用 RecyclerView，按作品 ID 恢复焦点。

## 设计契约

视觉与遥控器规则以 [DESIGN.md](DESIGN.md) 为准。`BrowseLayout` 按逻辑窗口宽度和字体倍率决定侧栏、可用空间与列数；正常960×540dp为首页7张、分类／片单6列、榜单5列、搜索结果3列。紧凑窗口和大字体降低列数，不靠修改设备密度或压缩字号适配。

`BrowseScaffold` 为浏览与详情共用侧栏和内容边距；`BrowseButton` 区分父标签、筛选、子榜胶囊、文字入口及主次操作，`BrowseStatus` 分离加载说明和可执行操作。详情使用平面 `DetailHeader`，正常窗口首屏呈现20集，完整简介使用弹窗；紧凑窗口仍可纵向到达全部选集。展开筛选限高裁切并在内部滚动，选项按宽度换行。

设置始终使用单列分组列表，方向键上下连续经过播放偏好、片单与设备、关于，并由整页滚动保持焦点可见。`TvGlyph` 按短边居中等比绘制；设置图标共用18dp绘制区域，原生开关滑块用等宽高外框和内边距保持圆形。

`BrowseButton.leadingIcon/trailingIcon` 将动作图标与文字分开，绘制时跟随文字颜色；详情状态变更同时更新文字和加号/勾选图标。首页翻页、分类与搜索下拉、详情和选集面板使用同一矢量图形。分类展开时只呈现一套主题选项；搜索引导集中在左栏，右栏按历史/等待/结果状态显示；详情集数只在元信息显示一次。二维码与备份弹窗均保持等比、关闭位图平滑插值。

图片加载区分CENTER_CROP与FIT_CENTER的解码目标，同时保留原有采样、缓存和内存上限。海报与焦点框采用相同圆角；不添加海报缩放动画或渐变背景。

遥控器自动激活通过`FocusActivation`与`RemoteFocus`实现：仅方向键产生选择意图，本地Tab延后到当前输入分发结束后切换，网络选择停留250ms；确认或进入内容可立即提交。侧栏复用实例，数据控件重建转移尚未到期的选择，不因程序恢复焦点重新请求。单选选择器显式启用，多选和操作按钮不启用。

## 内容契约

- 真人剧、漫剧、AI剧目录独立查询，默认按最高热度排序；重置恢复该默认条件。分类的 `default` 请求只取得动态字典，所有结果页均使用 `only_content`，从该结果页开始保存 `session_id`、`next_offset`；不混用初始化游标，不按返回条数推算偏移。
- 主题等维度保留上游字符串 ID 和选择规则。组合结果表达为平台筛选结果，不承诺严格交集。
- 榜单首批必须校验上层、子榜和面板选中回显。续页允许按协议省略选择器，但必须绑定已验证的查询及相同服务端会话。若上游演员入口没有子榜，展示该实际入口；请求不存在的子榜时拒绝静默回退。
- 面板空ID选项（如“总榜”）表示清空筛选，以空列表保存，不能存成含空字符串的列表。有上游默认项时不重复生成“全部”；全局单选清空全部条件，允许组合的榜单只清空当前维度。错榜回显校验继续保留。
- 人物使用单独条目类型，只打开资料；零集、禁止播放条目不进入播放器。不把推荐日志中的 rank 当作官方名次。
- 独立 AI 搜索尚未证实，界面明确提示暂不可用。全部剧集搜索是已支持真人剧、漫剧来源的综合结果，各自保存分页，失败显示缺失范围。

## 状态与资源

三类分类分别保存条件、已加载结果和网格锚点。首页每架最多保留54部；分类和榜单每个状态最多2400条元数据，达到预算时提示重新加载。视图只绑定附近条目，封面继续使用原有图片线程、取消和内存缓存预算。API26/27 对已验证的小说图片 HEIC 地址使用官网同资产的 JPEG rendition，不为封面额外请求剧集详情。

切换页面、条件或进入后台取消过期请求，迟到结果不能覆盖当前页面。分页无进展、空批或整批重复会停止自动追加并提供手动重试。同一查询刷新出错保留旧结果并明确标记；切换分类条件或榜单时清空旧查询条目，避免向下进入不匹配的内容。错误不能显示成有效空搜索。

手机扫码服务由搜索页面持有：随机路径、15分钟有效、连续提交、递增序号、频率限制与 Host/Origin 检查。刷新、离页、后台或网络地址变化使旧会话失效。范围切换保留二维码，每次提交绑定当时范围；令牌不落盘。

本机收藏、稍后看、观看记录与设置继续使用原有存储。备份写入v2，读取v1/v2；旧记录缺少类型时保持未知。原分集丢失时提示重新选集，不静默自动播放第一集。

## 验证与交付

需要 JDK17 和配置好的 Android SDK，在 `kotlin-tv/` 执行：

```sh
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

实时接口探针与离线 fixture 测试分别记录。构建、模拟器、真实电视/手机和发布验收属于不同证据级别。Debug 包沿用开发包名后缀，不是生产包升级产物。实际交付须记录源码提交、版本、递增构建号、包名、签名、大小、SHA-256；不覆盖同名交付文件。推送、发布与物理设备安装另按授权执行。
