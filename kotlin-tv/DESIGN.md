# hongguo 全应用设计方案 V2

## Overview

方向：深灰底、柔和玫红—暖橙主操作、白色文字、统一暖白焦点框。品牌色表达操作层级；焦点框表达遥控器当前能操作的位置。用户已确认此方向，本文件将其扩展到全应用，供后续实施。

状态：本文件是原生应用V2的设计与验收契约。代码通过共用样式和页面控件应用本规范；自动验证、模拟器和真机验收分别记录，不能把规范本身当作验收证据。过程材料放在忽略的 outputs 中。

范围：首页、真人剧／漫剧／AI剧分类、找剧、榜单、我的片单、详情、播放器、播放器选集、设置、所有应用内弹窗、版本更新，以及它们的加载／空／错误／禁用状态。手机扫码网页作为跨端配套单独约束，不将电视焦点框套到触屏。

沿用 Kotlin / View / Media3 与 app/core 分层，不更换框架，不新增业务入口，不升级依赖，不改变内容、存储或网络协议。搜索能力、真实集数与榜单类型以现有实现为准。设置页仅保留播放偏好与关于，不再提供手机备份恢复和恢复隐藏推荐入口；本机已有收藏、观看记录与隐藏状态继续保留。

参考基线：本会话确认的 V3 两张详情效果图。图片描述布局和状态意图，本文件参数优先于生成图中的像素、字号、假数据与重复图标。官方手机版公开图片只作为配色来源，不代表取得了官方品牌色板。

单个内容视图除海报、Logo、二维码和视频外，彩色表面原则上不超过可见面积5%；没有必要的主操作时可完全不使用渐变。每个弹窗作为独立视图同样最多一个主操作；主操作不能机械地分配给“删除”“取消”“刷新”等每一个入口。

禁用控件使用不透明低对比灰色表面与 disabled-text，不以降低整个容器透明度连带改变焦点或正文。无操作能力的控件移出方向键焦点链，仍可被辅助功能读到状态。

## Typography

沿用系统 sans-serif 与 sans-serif-medium。上方 YAML 中 px 为设计格式的名义逻辑尺寸：Android 字号映射 sp，长度映射 dp，禁止直接按截图像素填写。组件的 height／width 表示最小高度／宽度（图标、开关等固定图形除外）；渐变终点和描边拆成独立部件参数，供导出格式表达。HTML 样册仅用于屏幕浏览，不是 Android 渲染验证。

| 角色 | 正常字号 | 行为 |
| --- | --- | --- |
| 详情剧名 | 26sp／medium | 最多两行，长标题省略，完整名称在简介弹窗可读 |
| 页面标题／弹窗标题 | 24sp／22sp | 不放大为营销 Hero |
| 剧架／分组标题 | 18sp | medium；不伪装成可点击项 |
| 导航／主次按钮／设置项 | 16sp | medium；动作标签正常一行 |
| 正文／海报名／设置值／辅助操作 | 14sp | 正文行高1.5；海报名一行省略 |
| 帮助／时间／来源范围说明 | 12sp | 仍需远距离可读；关键错误与下一步操作用14sp |
| 海报非关键标签 | 11sp | 每项完整显示，最多3项，放不下隐藏该项 |

保留系统字体倍率。按钮宽度、高度用最小值，先增长与换行再滚动，不将16sp自动缩回13sp。1.3倍字体下单行动作行放不下时分成主操作行与次操作行，保持同一行内等高；不能截断“稍后看”等动作。长设置项允许两行，整行随内容增长。

## Layout

### 窗口与统一尺寸

正常基准960×540dp；紧凑基准640×360dp，以逻辑窗口和字体倍率判断，不用分辨率名称替代布局条件。1920×1080、320dpi是正常基准的一种设备条件，不据此修改设备密度。

| 参数 | 正常／紧凑规格 |
| --- | --- |
| 侧栏宽度 | max(正常165dp或紧凑148dp, 128dp×字体倍率)；仍须实测容纳四字导航＋图标与内边距，必要时增长 |
| 主内容左右边距 | 27dp／16dp；上下16dp／12dp，焦点外框不能被屏幕边缘或父容器裁切 |
| 页头 | 最小44dp，标题与工具操作垂直居中 |
| 主次动作 | 最小高44dp；主操作最小宽148dp，次操作104dp；左右内边距20dp／16dp |
| 分组／筛选／辅助操作 | 最小高40dp，宽度按标签测量；分组最小宽72dp，辅助操作80dp |
| 纯图标动作 | 最小44×44dp；主要图形20dp，辅助箭头16dp |
| 设置行 | 最小60dp；图标20dp、文字16sp、值14sp；当前值在箭头左侧右对齐，距行右缘36dp，与箭头间隔8dp；长文本可增长 |
| 集数 | 最小高44dp、宽56dp；横纵间距10dp；正常十列、紧凑或大字体最多五列 |
| 组内／区域间距 | 常规12dp／24dp；焦点外缘额外预留6dp |
| 海报 | 2:3，CENTER_CROP；标题及真实进度在海报下，不拉伸图像 |

焦点框3dp，深色间隔2dp，使用固定控件区域内的焦点容器绘制，以避免Android硬件绘制裁切外伸背景。框不改变控件测量尺寸，父层仍保留约6dp呼吸空间；不得挤压相邻控件或触发整页重排。

侧栏品牌区与底部设置固定，中间导航独立滚动。导航项普通、未选中且未聚焦时背景透明，只显示图标和文字；当前页保留中性选中底与左侧标识，聚焦时保留提亮背景与暖白焦点框。正常窗口导航行44dp，间隔6dp，品牌区约56dp；1.3倍字或紧凑窗口允许滚动，设置始终可达。品牌只出现一次。

海报高度还受实际内容视口约束：紧凑或大字体时，保留列宽供标题阅读，海报在列内以2:3等比居中缩小，避免单张封面大于视口导致标题与焦点永远无法完整露出。分类与榜单的选择器区域设最大高度并可滚动，内容仍保留可浏览空间。

### 内容密度修订

首页和分类为较大字号与焦点留白降低部分页面密度；搜索采用更小的封面与更窄的扫码面板，提高首屏结果数量。榜单正常仍为5列，不改变数据协议。列数是上限，实际由可用宽度、最小卡宽与字体倍率共同计算。

| 页面 | 正常、1倍字 | 紧凑、1倍字 | 正常、1.3倍字 | 紧凑、1.3倍字 |
| --- | --- | --- | --- | --- |
| 首页横向剧架 | 6张 | 3张 | 4张 | 2张 |
| 分类／片单 | 5列 | 3列 | 4列 | 2列 |
| 榜单 | 5列 | 3列 | 4列 | 2列 |
| 搜索结果（常驻二维码双栏） | 4列 | 2列 | 3列 | 1列 |
| 详情选集 | 10列×2行 | 5列，可滚动 | 5列，可滚动 | 5列，可滚动 |

计算基线：内容宽=窗口宽−侧栏−两侧边距；海报间距12dp；首页最小卡宽110dp、分类／片单128dp、榜单132dp、搜索116dp，最小卡宽按 max(1,字体倍率)增长。搜索二维码面板正常180dp、紧凑156dp，中栏间距20dp／16dp；二维码图形正常148dp、紧凑128dp，保留白色静区。

搜索面板只保留“扫码搜剧”、连接状态、同网提示、有效期及刷新；删除重复步骤说明。结果海报不超过140dp，并按可用高度为两行海报、标题和间距分配空间；高度不足时保留一行可滚动。真实封面和默认占位使用相同尺寸，保持2:3比例和14sp标题。结果首列向左进入刷新，向右返回结果。

**正常详情首屏预算：上下边距共24dp；页头44dp＋间隔8dp；详情块最多187dp；分隔留白10dp；分组工具行40dp＋间隔8dp；两行集数98dp；帮助行20dp。合计539dp。** 详情页正常窗口可用12dp上下边距，其他页面保持16dp。

为保留44dp按钮和20集，常态简介由旧规范最多3行改为最多2行；简介入口40dp与动作行44dp放在同一操作区、垂直居中。主操作148dp、收藏104dp、稍后看104dp、简介96dp，加3个12dp间距共488dp；正常741dp主内容扣除124dp海报及18dp列距，文案区599dp，可容纳此行。标题最多两行约68dp、元信息21dp、简介42dp、三处间隔共12dp、动作行44dp，共187dp；海报124×186dp。元信息保持单行省略，完整信息在简介弹窗可读。分组与刷新／跳转共用一行；焦点框预留由相邻留白与区域内衬共同提供。帮助行只作可选说明，不挤压正文和集数。

该预算是为放大控件做的明确布局调整，与V3过程图的“简介独占一行”不同。紧凑窗口与1.3倍字允许改行、降列、纵向滚动。正常窗口仍须用真实文字、字体及焦点外缘实测；如未满足20集首屏，继续调整非关键留白或文案结构，不能缩小字号或把推算当作验收。

## Elevation & Depth

通过纯色表面、区域留白、细分隔线与焦点框表达层次。浏览页不加大渐变Hero、磨砂、全屏光晕、投影或拉伸海报背景。只有主操作使用渐变；播放器控制层允许必要的黑色半透明遮罩保证文字清楚。

焦点表面变为 surface-focused，主渐变与当前集表面保留原色并叠加白框。当前集边1dp；焦点外框3dp。首页横向剧架内侧保留4dp动效安全区，卡宽与可用高度计算扣除双侧安全区。海报容器聚焦允许1.025倍轻缩放（140ms，失焦100ms），标题、按钮、集数与布局测量尺寸不缩放；扩张不得超过既有焦点留白。无呼吸、弹跳或自动滚动到页顶。白色焦点框立即跟随真实焦点，底色约120ms平滑提亮。按下只加约8%黑色遮层（进入60ms，松开约120ms恢复）；焦点与持久状态不消失。

加载不抢焦点，刷新不清空仍可用旧结果。进入新查询时明确更新状态，旧查询结果不能冒充新查询结果。状态栏不做可点击大卡片，只有重试／继续加载是操作控件。

### 页面与面板动效

- 侧栏稳定，一级内容区以180ms淡入、约8dp位移衔接；退出层约100ms退场，最多短暂保留一个退出层，退出层不参与方向键、点击或辅助功能访问。
- 进入详情以220ms衔接；先显示同一作品的海报、标题和加载状态，真实分集返回后补齐详情，不重新替换侧栏。返回恢复来源剧卡、分组与滚动位置。
- 动画可被新输入中断；视觉反馈即时生效，网络导航的250ms停留激活与确认键立即执行规则保持。恢复焦点不能触发自动选择。
- 可见网格项即时聚焦，离开安全视口才平滑滚动；返回锚点直接恢复。首页保留未变化剧架，追加仅新增卡片；图片缓存命中直接显示，首次异步图片约120ms淡入。
- 播放视频输出层不作缩放或位移动画；上方真实加载遮罩在首帧确认后约100ms退场，错误或取消立即收敛。控制层进入160ms、退出120ms；选集面板从右侧短距离进入180ms、退出140ms；普通弹窗进入140ms、退出100ms，均按原方向退回。
- 系统动画关闭时直接到最终状态；低内存设备关闭海报缩放和页面位移，面板使用短淡入。重要状态不依赖动画表达。
- 以上是实现参数和验收契约；真机流畅度须以同设备、同窗口、同字体、同缓存条件的录屏与帧耗时验证，不能把构建通过当作动效验收。

## Shapes

普通操作、选择器、集数与海报均8dp圆角；弹窗与独立面板12dp；开关轨道全圆角、滑块保持圆形。全应用不再用不同胶囊造型区分父标签与子榜，层级由所在行、文字、表面明度和分组关系表达。旧 CapsuleButton 后续映射到统一 choice 角色。

图标用TvGlyph矢量形状，统一24单位坐标和线宽，等比居中；动作图标20dp、尾箭头16dp。单个控件最多一个用于表达动作的图标；跳转只保留尾箭头，不前后堆双箭头。收藏用星形／勾选、稍后看用时钟／勾选；不可用字形字符替代返回、播放、刷新等图形。按钮图标一律跟随浅色文字。

二维码使用FIT_CENTER、黑白、不做圆角裁切模块或插值模糊。Logo原图保留，不因主题调整其颜色，不把新版官方Logo自动替换到本项目。

## Components

### 统一状态模型

| 状态 | 表现 | 方向键／确认 |
| --- | --- | --- |
| 普通 | 依角色采用轻灰、深灰、渐变；无白色外框 | 可聚焦 |
| 聚焦 | 3dp暖白外框＋2dp深色间隔；中性表面略提亮 | 全屏只有一个可操作焦点 |
| 按下 | 保留外框与文字，约8%黑色遮层 | 松开恢复，长按不重复触发收藏或播放 |
| 已选中、未聚焦 | 分组中灰底；多选勾选；当前集暗玫红与细边 | 不能伪装成焦点，不因经过而改变动作状态 |
| 已选中、聚焦 | 保留选中身份，再叠同一白框 | 白框始终优先可见 |
| 禁用 | 灰底与灰字、明确原因，无白框 | 跳过方向键焦点链，不跳过辅助功能说明 |
| 处理中 | 保留当前焦点与尺寸；主操作标签可变“正在处理…” | 去重，同一动作不能并发重复提交 |

当前集下方没有任何横线、短划、播放进度小线。需要说明身份时在选集区标题旁用一次“正在播放第N集／上次看到第N集／待播第N集”，按真实状态选择，不能用“正在播放”描述尚未播放的内容。数字本身不增加角标。

主操作渐变不等于焦点；焦点移开后渐变保留、白框移走。收藏等持久状态配文字“已收藏”“已在稍后看”，不能仅改变颜色。海报进度表示真实观看进度，不作为选中指示。

### 全局遥控器规则

- 浏览采用方向键移动、确认执行、返回退出当前层。所有页面建立页头／选择器／内容／状态操作的清晰分组，不在文字段落中插入不可见的焦点停靠点。
- 一个区域记住最后稳定焦点，以作品ID、控件角色和分组ID保存；向下进入内容时恢复原位置，无记录才选首项。网格上下尽量同列，不存在时选最近有效项。左右边缘停留；内容首列左键可回侧栏，右键恢复原内容位置。
- 不可点击标题、正文、海报装饰图、二维码本身不单独占焦点；长简介需要滚动时将滚动正文作为单一焦点区域，并标明上下滚动。
- 分组很多或标签变长时，分组条在自身区域横向滚动，聚焦项自动露出；不能扩展为挤走集数的多行标签。正常操作标签按实际文字测量增长，不把最小宽度当固定截断宽度。
- 原有自动激活保留：侧栏、网络榜单与单选筛选停留250ms提交；本地片单Tab及选集分组在当前方向键事件结束后切换。快速经过取消过期请求；确认／离开横向区进入内容时提交尚未生效的选择。
- 自动激活只适用于浏览位置或单选条件，绝不适用于播放、收藏、稍后看、多选、刷新、删除、设置修改或更新安装。程序恢复焦点、网络重建与弹窗关闭不产生自动选择意图。
- 切组、刷新和分页不抢走当前焦点，不因上游慢响应跳回旧组。焦点对象消失时按同组最近项→同区域入口→侧栏当前项顺序回退。
- 返回先关闭弹层，再收起筛选／控件层，再返回上一页面；保持现有页面返回语义，不能形成无限循环。
- 初次使用可显示底部12sp上下文帮助；常用后允许隐藏，重要操作不能仅靠帮助文字可发现。帮助只描述当前焦点执行的真实动作。

### 弹窗、开关与进度的统一补充

- 中央弹窗宽min(460dp,窗口宽−两侧各32dp)，高不超过窗口80%；长内容滚动，动作区可达。选集侧栏采用上表独立尺寸。紧凑窗口弹窗适当降低内边距到16dp，控件最小高度不降低。
- 对话框不套平台默认强调色；背景、正文、列表、按钮、选中勾选、焦点和按下均显式使用语义色，防止再次出现强调色底配黑字。
- 自动连播开关不新增单独滑块焦点；整行是一个焦点目标，确认切换并自动保存；开启为暗玫红轨道＋右侧暖白圆形滑块，关闭为灰轨道＋左侧滑块，辅以“开／关”读屏状态，不依赖绿色。
- 播放进度条仅表达时间；播放位置、当前集身份和焦点三者分开。收起控件时的左右快进退是现有播放器模式，不能推广成浏览页左右即执行动作。
- 应用仅控制自身弹窗；系统安装器、系统权限和系统键盘按系统交互处理，不能声称主题覆盖这些外部界面。

## Do's and Don'ts

### 验收矩阵

- 窗口／字体：960×540dp与640×360dp，各覆盖1与1.3倍；记录截图像素、密度、字体倍率、真实内容、焦点ID与页面状态。正常详情首屏20集；其余条件可滚动，不能缩字号补容量。
- 每类控件：普通、聚焦、按下、选中未聚焦、选中聚焦、禁用、处理中；当前集、当前页、当前单选与焦点允许共存，但屏幕仅一个白色焦点框。
- 页面：上表所有页面至少正常与非正常状态各一项；搜索常驻二维码、片单为空、榜单人物项、播放器错误与首末集、设置末行、长弹窗必须单独覆盖。
- 方向键：首末边界、上下同列、跨区域往返记忆、返回恢复、快速切组、长按、内容刷新与焦点重建；联网与纯本地场景分开记录。
- 可读性：白字与整个渐变采样、中性文字与表面、焦点与背景、当前集细边；数值检查之外，在真实电视观看距离确认字重、亮度与焦点辨认。
- 自动验证：实施后在kotlin-tv执行`:core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`；不把HTML样册键盘演示当作原生测试；实际执行结果见验证报告。
- 真实验收：模拟器和真机分开；真机安装、打包、推送与发布各按相应授权处理。系统安装界面不计为主题可控区域。

### 完成定义

全应用完成需要共用参数、所有页面及弹层改造完成，规范与实现无冲突，四组窗口／字体检查及方向键流程通过；构建通过仅是一项证据。实际通过范围以本地验证报告为准；未做的真机或外部安装验收不得标记为通过。

禁止：当前集下划线、主色黑字、满屏红底、每个按钮都渐变、焦点闪烁、文字入口过小、单靠色彩区分状态、隐藏可操作区、靠修改设备密度适配、把生成图片标为真机截图、把现有未提交工作合并到本方案提交。
