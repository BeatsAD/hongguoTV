# 红果 TV 原生设计规范 V1

## Overview

适用于 kotlin-tv 的 Kotlin / 原生 View 浏览界面；沿用 app/core 与 Media3。设计基线为最终原型：首页v7、分类v6、搜索v9、榜单v10、详情图；最终全局规则优先于旧版单页截图。本规范将原型转换为可实施参数，不以截图中假数据作为产品数据。

## Colors

采用以上统一颜色。珊瑚红用于主操作、当前子榜和当前选集；正文浅白，次要信息灰色。珊瑚底使用深色文字。当前页面的浅灰底和左侧珊瑚条表达位置，白色描边表达遥控器焦点，两者可同时出现。不要把全部控件都填充为强调色。

## Typography

使用系统 sans-serif，不新增字体依赖；尺寸为sp，间距为dp，不把物理像素当作dp。文件头的px是DESIGN.md格式的名义逻辑尺寸：字体映射sp、圆角映射dp，并非屏幕物理像素；下表与原生实现为规范值。

| 角色 | 正常字号 | 规则 |
| --- | --- | --- |
| 首页标题 | 22sp | 中等字重，一行 |
| 其他页标题 | 24sp | 一行，页头允许辅助入口 |
| 剧架标题 | 16sp | 中等字重 |
| 导航 | 14sp | 四字导航完整可读，不用省略掩盖宽度问题 |
| 海报标题 | 13sp | 单行省略，固定基线；详情可显示全名 |
| 正文／按钮 | 13sp | 标准系统字重 |
| 状态与辅助文字 | 11sp | 不伪装成按钮 |
| 海报标签 | 9sp | 单行完整标签，放不下整项隐藏，最多3项 |

保留系统字体倍率。大字体改列数、换行和滚动空间，不能自动缩字抵消用户设置。

## Layout

正常基准为960×540dp（1920×1080、320dpi、字体倍率1）。正常侧栏165dp，主内容左间距27dp、右间距26dp，上下16dp；页头高约36dp、下间距10dp。紧凑基准640×360dp，侧栏148dp，主内容左右16dp、上12dp。侧栏品牌区、导航、底部设置共用一个框架，导航必要时独立滚动，设置仍可到达。

| 页面 | 正常 | 紧凑或大字体 |
| --- | --- | --- |
| 首页横向剧架 | 7张 | 紧凑正常字4张，正常窗口1.3倍字5张，紧凑1.3倍字3张 |
| 分类／片单网格 | 6列 | 最小卡片约100dp，降列 |
| 榜单网格 | 5列 | 最小卡片约120dp，降列 |
| 搜索结果 | 3列 | 双栏右区至少一列可读卡片，降列 |

首页剧架间距12dp，卡片对齐顶部；分类等网格间距约12dp。筛选展开区限高并可纵向滚动，不把海报完全挤出屏幕。连续网格沿用真实分页游标，榜单五列不改变数据协议。

正常字号、正常窗口下，详情首屏显示：一处返回、海报与说明、三项主操作、20集（两行十列）。紧凑屏和大字体以可读性与可滚动到达为先，不缩小文字强塞20集。

## Elevation & Depth

使用纯色、细分隔线和轻微色差划分层级。浏览页不增加大块渐变Hero、模糊、投影或海报背景拉伸。加载提示采用灰色状态行，仅失败重试或确实可追加时有文字操作入口。

## Shapes

海报2:3，CENTER_CROP，圆角8dp；白色焦点环沿同一8dp圆角，2dp描边。普通按钮和面板圆角6至8dp。仅子榜等真正的胶囊使用全圆角；父分类用下划线标签，筛选用较轻的矩形选项。图标采用同一24单位绘制坐标与一致线宽。

## Components

- 共用框架：品牌、首页、搜索、榜单、我的片单、三类片库、设置。详情保留来源页面选中态，返回恢复原剧卡、筛选和滚动位置；点击侧栏可导航至对应页面。
- 页头：标题左对齐。首页右侧紧凑搜索入口含图标和提示文字；搜索范围在页头，使用选择器，禁止额外一行四个大胶囊。
- 文字入口：用于“全部真人剧”、刷新、完整简介和跳转，不加厚填充。主操作：珊瑚底深色字；次操作：深灰矩形；父标签：无填充、选中下划线；子榜：深灰／珊瑚胶囊；筛选：轻矩形。
- 海报：最多3个真实去重题材在左上角，右下“全N集”；标题下不重复集数；无集数不显示，不伪造演员集数。续播可显示真实进度和继续集数。
- 首页：三类横向剧架，加载范围提示和前后移动可操作；无有效历史隐藏“接着看”。首项左键回导航，末项右键停留，详情返回恢复位置。
- 搜索：左侧二维码面板含连接状态、步骤、有效期和刷新；右侧历史紧凑换行、等待说明或结果；保持唯一手机文字入口、常驻二维码和连续发送；“清除结果”返回历史／等待态并保留当前二维码，离开关闭会话。
- 榜单：上层六类为下划线标签，子榜为胶囊；真实名次才显示数字，不用数组位置伪造官方排名；特殊人物、预约条目保留原行为。
- 分类：常用选项与更多，展开后维度名在左、选项在右按宽度换行；沿用维度ID与互斥规则；返回先收起筛选。
- 详情：平面海报／文案双栏，标题最多两行，简介最多三行；完整简介使用弹窗；主操作仅播放／收藏／稍后看。选集组使用下划线，当前集珊瑚底，刷新为次级操作。
- 片单：父标签切换收藏、稍后看、历史，并显示真实数量；共用海报与焦点规则。设置沿用现有功能，标准行高至少54dp，面板圆角8dp、双栏间隔22dp，统一标题、字级与焦点。

## Do's and Don'ts

- 实现使用统一的TvStyle、BrowseLayout与语义控件，不在页面复制一组互相矛盾的常量。
- 遥控器上下左右边界明确；焦点不进入不可见、禁用或已移除的控件；长按／菜单管理与返回定位必须保留。
- 图片解码尺寸匹配CENTER_CROP显示区域，并保留内存、磁盘缓存预算；二维码不使用模糊插值。
- 视觉验收记录窗口像素、密度、字体倍率、页面状态和焦点位置；同条件对照完整画面与局部，不把不同数据、无历史或设计过程文案当缺陷。
- 至少覆盖960×540dp、640×360dp、字体倍率1与1.3；正常详情首屏20集；导航无省略、设置可达、筛选可收起、历史可连续发送与返回可恢复。
- 必跑:core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug。模拟器结果与真机验收分别记录。
- 构建／安装保留版本、递增构建号、源码提交、签名、大小与SHA-256；覆盖安装保留数据，不卸载或降级绕过。设计过程、截图、日志和APK放outputs，不推送或发布。
